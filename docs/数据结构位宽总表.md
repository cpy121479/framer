# uvm_koa 方案数据结构位宽总表

> 用途：核对全方案数据结构定义完整性。已定义的写实际位宽；未定义的标 **待定**；
> 模型占位用 `（占位）` 标注。请检查后在表格中补充位宽。

## 1. KO 报文（48B = 384bit，6×8B）

### 1.1 第一行（8B，所有模板相同）

| 字段 | 位宽 | 含义 |
| --- | --- | --- |
| DA | 1B | 宿端地址 |
| DP | 1B | 宿端端口 |
| SA | 1B | 源端地址 |
| SP | 1B | 源端端口 |
| TYPE | 1B | 报文类型 |
| PRI | 3bit | 优先级（0 最高） |
| SN | 13bit | 序号 |
| B/E/LBO(CHN) | 1B | 边界/末标记/低字节优先（通道），内部位域待定 |

### 1.2 四种模板（第 2~6 行，40B）

| 模板 | 内容 | 未定义部分 |
| --- | --- | --- |
| KO 开销报文 | 第 2 行 8B + 第 3 行前 4B = 开销头，其余 META | 开销头字段、META 细分布宽 |
| KO IO 报文 | 除第 1 行外全 META | META 细分布宽 |
| KO 控制报文 | 第 2 行 = 控制头，其余 RES | 控制头字段、RES |
| KO DMA 报文 | 第 2~3 行 = DMA META，其余 RES | DMA META 字段、RES |

## 2. burst（32bit = 4B，已定义）

> 一种结构、两种类型，由 `burst_type` 区分（0=i/v_task，1=c_task），字段不完全相同：
> 部分字段按类型复用同一比特位（i/v 与 c 字段重叠布局）。

| 字段 | 位宽 | 适用类型 | 含义 |
| --- | --- | --- | --- |
| st | 1bit | 公共 | 是否为所属 ts 的首个 burst |
| tr | 1bit | 公共 | 是否涉及 O 窗操作 |
| ts_len | 3bit | 仅 i/v | 所属 ts 包含 burst 数 |
| branch | 1bit | 仅 i/v | 是否可能存在 ts 跳转 |
| rev | 4bit | 仅 c_task | 保留位（与 iv 的 ts_len+branch 复用 4bit） |
| burst_type | 1bit | 公共 | 0=i/v_task，1=c_task |
| vld_cu | 1bit | 公共 | 需执行 task 数：0=1 个，1=2 个 |
| tsk_id0 / tsk_id1 | 3bit / 3bit | 仅 i/v | 任务 id，查 CSR.vtsk_c（与 dma_id0/1 复用 6bit） |
| c0 / c1 | 1bit / 1bit | 公共 | 任务0/1 有效标志（0=无效） |
| sub_pc0 / sub_pc1 | 8bit / 8bit | 仅 i/v | task 指令集指针（与 occ_ts0/1 复用 16bit） |
| dma_id0 / dma_id1 | 3bit / 3bit | 仅 c_task | 任务 id，查 CSR.dma_c |
| occ_ts0 / occ_ts1 | 8bit / 8bit | 仅 c_task | c_task 占据的 ts 数 |

位宽核对：`st1+tr1+[ts_len3+branch1|rev4]+burst_type1+vld_cu1+[tsk_id6|dma_id6]+c0/c1 2+[sub_pc16|occ_ts16] = 32bit`。

## 4. CSR 表项（每线程 1 项）

| 字段 | 位宽 | 含义 | 状态 |
| --- | --- | --- | --- |
| err | 1B | 线程错误指示（默认 0） | 刷新条件待定 |
| ccr | 8B | 待定 | 语义待定 |
| sys_ts | 6B | 系统时戳（线程启动时间） | 已定义 |
| th_id | 6bit | 线程 id（64 线程） | 已定义 |
| th_stat | 1B | 线程状态（IDLE/READY/ISSUED/DONE） | 已定义 |
| o_mes | 1B | O 窗操作/状态指示 | 语义待定 |
| cur_ts | 1B | 当前 ts | 已定义 |
| vtsk_c | 1B | i/v 任务执行掩码（tsk_id 查询） | 位宽已定义，用途待 CU 实现 |
| dma_c | 1B | c_task 执行掩码（dma_id 查询，8bit 对应 cw 8 项） | 已定义 |
| tw | 8×1B | 待定 | 语义待定 |
| cw | 8×6B | c_task 操作表（dma_id 索引） | 条目位域见 4.1 |

### 4.1 CSR.cw 条目（6B = 48bit，已定义）

| 字段 | 位宽 | 含义 |
| --- | --- | --- |
| tag | 20bit | smc 地址（= op_addr） |
| op_type | 1bit | loc/free：0=loc，1=free |
| r | 1bit | c_line 有效；smc 读出数据刷新 c 窗 c_line 后写 1 |
| o | 1bit | 1=该线程占据该 c 窗资源 |
| c_line_num | 8bit | c 窗资源号（64×4=256 个资源） |
| start_ts | 8bit | 起始 ts |
| occ_ts | 8bit | 占据 ts 数 |
| rsv | 1bit | 保留 |

位宽核对：`20+1+1+1+8+8+8+1 = 48bit`。

## 5. C 窗

| 结构 | 定义 | 状态 |
| --- | --- | --- |
| C 窗缓存 | 64（线程）× 8（槽位）× 21B | 条目 168bit（21B） |
| C 窗资源池 FIFO | 256 深 × 资源号 8bit | 已定义 |
| 单线程资源上限 | 4 | 已定义 |

### 5.1 C 窗资源条目（168bit = 21B，已定义）

| 字段 | 位宽 | 含义 |
| --- | --- | --- |
| tag | 20bit | smc 地址 |
| c_line | 128bit | 行数据（free 时经 RBA 写 SMC） |
| d | 1bit | 数据 dirty：申请后 0，CU 改写 c_line 后 1 |
| o | 1bit | 占用标志：申请到资源后写 1 |
| r | 1bit | c_line 有效：smc 读出数据刷新 c 窗 c_line 后写 1 |
| cnt | 9bit | 老化计数：超上限强制释放（o=0，资源号入 FIFO） |
| ind | 8bit | c 窗资源号（64×4=256 个资源） |

位宽核对：`20+128+1+1+1+9+8 = 168bit`。
